# Recetitas
proyecto simple para subir recetas y clasificarlas segun antojitos 

esto va simple, este monorepo funciona por sub division de carpetas, es mono repo de nombre, en apps estan ambas divisiones, web para front y API para back, el deploy ya se como hacerlo igual, lo unico importante es que cada instalacion de dependendecias hay que hacerlas en las carpetas correspondientes

# Instalacion de dependecias
 - hacemos un cd apps/(web para front, api para back) y recien ahi hacemos las intalaciones con "pnpm" 

# Que usamos 
estamos usando react y node.js con express y para que sea totalmente mobile igual se esta usando  PWA y CORS

# Como levantamos 
con pnpm dev levanta todo ya esta configurado
